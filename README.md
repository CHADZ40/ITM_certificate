## 📌 Project Overview

Creating and distributing certificates manually for large events, courses, or webinars is time-consuming. **CertGen** solves this problem by automating the entire process:

1. **Reads Participant Data:** Pulls attendee details directly from an `.xlsx` file.
2. **Generates Custom PDFs:** Dynamically injects dynamic names into an HTML/CSS template and compiles individual PDF files.
3. **Automates File Naming:** Formats and saves files consistently (e.g., `Certificate_John_Doe.pdf`) without manual intervention.
4. **Enables Self-Service Downloads:** Provides a lightweight web search page where attendees can type their name and grab their certificate instantly.
