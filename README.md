## About

**ITM Innovation Hackathon** is a student-led initiative designed to bring together students to collaborate, innovate, and turn their creative ideas into reality. This platform handles event promotion, participant registration, and project tracking to empower student builders throughout the hackathon.

The project features a responsive web interface integrated with dynamic Google Apps Script handlers to manage submissions, participant workflows, and certificate searches seamlessly.

## Project Plan

### Key Features

- [x] Group Showcase — Displays group names, team member lists, and full project overviews
- [x] PDF Download Portal — Direct access for users to download project files and certificates in PDF format
- [x] Search & Filter — Quick searching to find specific groups or team members

### Technical Highlights

- [x] Semantic **HTML5** structure styled with **Bootstrap** and **CSS**
- [x] Dynamic submission forms powered by **Google Apps Script** and **Google Sheets** backend
- [x] Fully responsive layout optimized for mobile, tablet, and desktop viewports
- [x] Interactive UI elements with custom JavaScript input validation
